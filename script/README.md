## Command line utilities

|file   |description                       |dependency|
|-------|----------------------------------|----------|
|bin2hex|convert binary file to Intel hexa |objcopy   |
|hex2bin|convert Intel hexa file to binary |objcopy   |
|lst2asm|convert list file to assembly     |awk       |
|lst2bin|convert list file to binary       |awk       |
|md2html|convert Markdown file to html     |pandoc    |
|opdict |opcode dictionary                 |awk       |
