# CoreLAB

## Intel 4004 microprocessor

### Technical Parameters

|Parameter                       |Specification                                 |
|--------------------------------|--------------------------------------|
|**Release date**                |November 1971                         |
|**Process technology**          |10 µm silicon-gate PMOS               |
|**Transistor count**            |~2,300                                |
|**Architecture**                |Harvard                               |
|**Data bus width**              |4-bit                                 |
|**Address bus width**           |12-bit (multiplexed)                  |
|**Maximum addressable memory**  |4 kB program ROM; 640 × 4-bit data RAM|
|**Maximum addressable I/O area**|External MCS-4 I/O devices            |
|**Clock speed**                 |500-740 kHz                           |
|**Stack**                       |3-level program-address internal stack|
|**General purpose registers**   |R0-R15 (sixteen 4-bit registers)      |
|**Special registers**           |A, PC, C                              |
|**Interrupt handling**          |No hardware interrupt mechanism.      |

**Flag abbreviations:**

* **C** - Carry Flag
