# CoreLAB

## Intel 4040 mikroprocesszor

### Műszaki paraméterek

|Paraméter                            |Specifikáció                                   |
|-------------------------------------|-----------------------------------------------|
|**Megjelenés dátuma**                |1974                                           |
|**Gyártástechnológia**               |10 µm szilíciumkapus PMOS                      |
|**Tranzisztorszám**                  |~3 000                                         |
|**Architektúra**                     |Harvard                                        |
|**Adatbusz szélessége**              |4 bites                                        |
|**Címbusz szélessége**               |12 bites (multiplexelt)                        |
|**Maximálisan címezhető memória**    |8 kB program ROM; 1280 × 4-bit adat RAM        |
|**Maximálisan címezhető I/O-terület**|Külső MCS-40 I/O-eszközök                      |
|**Órajel-frekvencia**                |500-740 kHz                                    |
|**Verem**                            |7 szintű, belső programcím-verem               |
|**Általános célú regiszterek**       |R0-R23 (huszonnégy 4 bites regiszter)          |
|**Speciális regiszterek**            |A, PC, C                                       |
|**Megszakításkezelés**               |Egy maszkolható hardveres megszakítási bemenet.|

**Jelölések:**

* **C** - Átviteljelző

### Műveleti kódok

|műv. kód|mnemonik |méret|ciklus|jelző|
|:------:|:--------|----:|-----:|-----|

**Megjegyzések:**  

 - 11: JNT (ugrás ha TEST = 0)
 - 12: JC (ugrás ha C = 1)
 - 14: JZ (ugrás ha A = 0)
 - 19: JT (ugrás ha TEST = 1)
 - 1A: JNC (ugrás ha C = 0)
 - 1C: JNZ (ugrás ha A <> 0)
 - 40–4F (JUN) és 50–5F (JMS): a második hexa digit az ugrási cím része.
