# CoreLAB

## Intel 8080 microprocessor

### Technical Parameters

|Parameter                       |Specification                                                                                   |
|--------------------------------|------------------------------------------------------------------------------------------------|
|**Release date**                |April 1974                                                                                      |
|**Process technology**          |6 µm NMOS                                                                                       |
|**Transistor count**            |~4,500 (LSI)                                                                                    |
|**Architecture**                |Neumann                                                                                         |
|**Data bus width**              |8-bit                                                                                           |
|**Address bus width**           |16-bit                                                                                          |
|**Maximum addressable memory**  |64 kB                                                                                           |
|**Maximum addressable I/O area**|256 ports (8-bit I/O address space)                                                             |
|**Clock speed**                 |2 MHz (Intel 8080A), up to 3.125 MHz (8080A-1)                                                  |
|**Stack**                       |External, RAM-based via Stack Pointer                                                           |
|**General purpose registers**   |A, B, C, D, E, H, L                                                                             |
|**Special registers**           |PC, SP, Flags                                                                                   |
|**Interrupt handling**          |One maskable interrupt; the interrupt vector is supplied externally as an instruction (RST 0-7).|

Flag abbreviations:

* **S** - Sign Flag
* **Z** - Zero Flag
* **A** - Auxiliary Carry Flag
* **P** - Parity Flag
* **C** - Carry Flag

### Opcodes

**Notes**:  

- `/`: operation occurs/does not occur.
- `*`: alternative opcodes; must not be used.
- `d8` or `d16`: 8-bit or 16-bit immediate data.
