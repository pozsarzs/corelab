## T4004CPU from TCPU class in cpu_4004 unit

`T4004CPU` is the Intel 4004 processor implementation for the CoreLAB framework.
It derives from `TCPU` and provides the 4004 register structures, CPU configuration,
reset operation, state persistence, instruction stepping, current-instruction
reporting and register access.

The actual instruction implementation is included from
`cpu_4004_microcode.pas` during compilation.

### CPU configuration

The constructor configures the inherited `TCPU` properties as follows:

|item                    |value                      |
|------------------------|---------------------------|
|Module name             |`4004`                     |
|Description             |`Intel 4004 microprocessor`|
|Architecture            |`arHarvard`                |
|Address width           |12                         |
|Endianness              |`enLittle`                 |
|Maximum memory address  |`$00FF`                    |
|Maximum code address    |`$0FFF`                    |
|Maximum I/O port address|`$000F`                    |
|Separate I/O bus        |`True`                     |
|Default clock frequency |500000 Hz (500 kHz)        |

The implementation identifies the bus type as `btMCS4`. It connects to an
`IMCS4Bus` interface.

### Reset state

`Reset` clears the execution state, counters, register record, internal stack
record and carry flag, then emits the inherited `ceReset` event.

|register/state     |value  |
|-------------------|-------|
|`PC`               |`0`    |
|`A`                |`0`    |
|`CCR`              |`0`    |
|`Running`          |`False`|
|`Halted`           |`False`|
|`FFlags.C`         |`False`|
|`TotalCycles`      |`0`    |
|`TotalInstructions`|`0`    |

### Instruction execution

`Step` performs the following operations:

1. Exits immediately if the CPU is disabled (`FEnabled = False`).
2. Exits immediately if the CPU is halted (`FHalted = True`).
3. Reads an opcode from ROM at the current program counter using `FBus.ReadROM`.
4. Stores the current address, opcode, zero cycle count and zero operand count
   in `FLastInstruction`.
5. Increments `PC` and applies the 12-bit program-counter mask (`FPCMask`).
6. Calls `RunOpCode` to execute the opcode.
7. Adds the instruction cycle count to `FTotalCycles`.
8. Emits `ceInstructionBoundary`.
9. Increments `FTotalInstructions`.

### Register and flag structures

`T4004Registers` defines the processor register storage:

|field|width / type   |description                            |
|-----|---------------|---------------------------------------|
|`R`  |array of `Byte`|Sixteen general-purpose 4-bit registers|
|`A`  |`Byte`         |4-bit accumulator                      |
|`PC` |`Word`         |12-bit program counter                 |
|`CCR`|`Byte`         |3-bit command control register         |

`T4004Flags` contains one Boolean carry flag:

|flag|type     |description|
|----|---------|-----------|
|`C` |`Boolean`|Carry flag |

The source declares `T4004Stack` as a three-level program-counter stack:

|field    |type           |description                  |
|---------|---------------|-----------------------------|
|`Pointer`|`Byte`         |Stack pointer                |
|`Regs`   |array of `Word`|Stored program-counter values|

### Register access

`GetRegister` and `SetRegister` convert the supplied register name to uppercase.
The supported names are `R0` through `R15`, `A` and `PC`.

|register       |width |readable|writable|
|---------------|------|--------|--------|
|`R0`–`R15`     |4 bit |Yes     |Yes     |
|`A`            |4 bit |Yes     |Yes     |
|`PC`           |12 bit|Yes     |Yes     |

`SetRegister` masks `R0`–`R15` and `A` to the low four bits. It masks `PC`
with `FPCMask`, which is initialized to `$0FFF`.

The public register enumeration contains 18 entries:

|index|name |size     |
|-----|-----|---------|
|0    |`R0` |1 nibble |
|1    |`R1` |1 nibble |
|2    |`R2` |1 nibble |
|3    |`R3` |1 nibble |
|4    |`R4` |1 nibble |
|5    |`R5` |1 nibble |
|6    |`R6` |1 nibble |
|7    |`R7` |1 nibble |
|8    |`R8` |1 nibble |
|9    |`R9` |1 nibble |
|10   |`R10`|1 nibble |
|11   |`R11`|1 nibble |
|12   |`R12`|1 nibble |
|13   |`R13`|1 nibble |
|14   |`R14`|1 nibble |
|15   |`R15`|1 nibble |
|16   |`A`  |1 nibble |
|17   |`PC` |3 nibbles|

`GetRegisterCount` returns the number of entries in `PubRegNames`.
`GetRegisterName` returns the name for a valid index and `nil` otherwise.
`GetRegisterSize` returns the corresponding size in nibbles and `0` for an
invalid index.

`CCR`, the carry flag and the internal stack are not included in the public
register enumeration.

### Current-instruction information

`GetCurrentInstruction` returns a `TLogRec` containing the total instruction
count, the instruction address, the raw opcode text, the mnemonic, the last
instruction cycle count and the accumulated cycle count.

The address is formatted as four hexadecimal digits. The opcode is formatted
as two hexadecimal digits. If `FLastInstruction.NumOperand` is greater than
zero, up to two operand bytes are appended to the raw opcode text and to the
mnemonic. Operand bytes are formatted as two hexadecimal digits.

### State persistence

`LoadState` reads the following data in order:

|order|data                |
|-----|--------------------|
|1    |`FEnabled`          |
|2    |`FRegs`             |
|3    |`FFlags`            |
|4    |`FStack`            |
|5    |`FLastInstruction`  |
|6    |`FRunning`          |
|7    |`FHalted`           |
|8    |`FTotalCycles`      |
|9    |`FTotalInstructions`|

If a stream exception occurs, `LoadState` returns `False`; otherwise it
returns `True`.

`SaveState` writes the same fields in the same order and returns `True` after
the write operations complete.

**Serialization limitation:** `FRegs` and `FStack` contain dynamic arrays.
The implementation writes and reads these records using `SizeOf` and
`ReadBuffer`/`WriteBuffer`; this serializes the record storage, not the
allocated contents of the dynamic arrays. The bus reference, ROM bank, stack
size, program-counter mask and TEST pin are not included in the saved data.
