## T8008CPU from TCPU class in cpu_8008 unit

`T8008CPU` is the Intel 8008 processor implementation for the CoreLAB framework.
It derives from `TCPU` and implements the Intel 8008 register set, flag handling,
reset operation, state persistence, instruction stepping, interrupt reporting,
current-instruction reporting and register access.

The actual instruction implementation is included from `cpu_8008_microcode.pas`
during compilation. Therefore, the instruction set behaviour is distributed
between this unit and that included microcode source.

### CPU configuration

The constructor configures the inherited `TCPU` properties as follows:

|item                    |value                      |
|------------------------|---------------------------|
|Module name             |`8008`                     |
|Description             |`Intel 8008 microprocessor`|
|Architecture            |`arNeumann`                |
|Address width           |14                         |
|Endianness              |`enLittle`                 |
|Maximum memory address  |`$3FFF`                    |
|Maximum code address    |`$3FFF`                    |
|Maximum I/O port address|`$001F`                    |
|Separate I/O bus        |`True`                     |
|Default clock frequency |500000 Hz (500 kHz)        |

### Reset state

`Reset` clears the complete `T8008Registers`, `T8008Stack` and `T8008Flags`
records. It also clears the execution and interrupt state and counters.

|register/state     |value  |
|-------------------|-------|
|`A`                |`$00`  |
|`B`                |`$00`  |
|`C`                |`$00`  |
|`D`                |`$00`  |
|`E`                |`$00`  |
|`H`                |`$00`  |
|`L`                |`$00`  |
|`PC`               |`$0000`|
|`Running`          |`False`|
|`Halted`           |`False`|
|`FIRQPending`      |`False`|
|`FNMIPending`      |`False`|
|`TotalCycles`      |`0`    |
|`TotalInstructions`|`0`    |

The four flags `C`, `Z`, `S` and `P` are also cleared. The internal seven-level
hardware stack is cleared and its pointer is reset as part of the record
initialization.

The method emits the inherited `ceReset` event.

### Instruction execution

`Step` performs the following operations:

1. Stops immediately when the CPU is disabled (`FEnabled = False`).
2. Calls `CheckInterrupts`; execution stops immediately when an interrupt is accepted.
3. Stops immediately if the CPU is halted.
4. Reads the opcode from the system bus at the current `PC`.
5. Stores the address, cycle count, opcode and operand count in `FLastInstruction`.
6. Increments `PC` and limits it to the 14-bit address range with `$3FFF`.
7. Includes and executes the instruction implementation from
   `cpu_8008_microcode.pas`.
8. Adds the instruction cycle count to `FTotalCycles`.
9. Emits `ceInstructionBoundary`.
10. Increments `FTotalInstructions`.

The source therefore requires a connected `FBus` for opcode fetching.

### Flag handling

`UpdateFlags` calculates the Intel 8008 flags from a 16-bit arithmetic result.

|flag|condition                            |
|----|-------------------------------------|
|`C` |bit 8 of the result is set           |
|`Z` |the low 8 bits of the result are zero|
|`S` |bit 7 of the low 8 bits is set       |
|`P` |the low 8-bit result has even parity |

The implemented flag set is therefore Carry, Zero, Sign and Parity.

### Interrupt handling

`DoInterrupt` calls the inherited interrupt handler. When `AEvent` is
`ceInterrupt`, the method contains the location for Intel 8008 restart (RST)
handling, but the current source does not implement additional RST behaviour
there.

`GetCurrentInterrupt` reports the current IRQ vector from `FIRQVector` as a
two-digit hexadecimal value. Its `Status` is `Pending` when `FIRQPending` is
set; otherwise it is empty. The `Sender` field is empty.

### Current-instruction information

`GetCurrentInstruction` returns a `TLogRec` containing:

1. the total instruction count;
2. the instruction address as four hexadecimal digits;
3. the opcode as a two-digit hexadecimal string;
4. up to two encoded operand values;
5. the mnemonic followed by the formatted operands;
6. the cycle count of the last instruction;
7. the accumulated total cycle count.

Operand values are formatted as two-digit hexadecimal values. If two operands
are present, they are separated by a comma in the formatted mnemonic.

### Register access

`GetRegister` and `SetRegister` compare register names case-insensitively
using `UpperCase`.

|register|width |readable|writable|
|--------|------|--------|--------|
|`A`     |8 bit |Yes     |Yes     |
|`B`     |8 bit |Yes     |Yes     |
|`C`     |8 bit |Yes     |Yes     |
|`D`     |8 bit |Yes     |Yes     |
|`E`     |8 bit |Yes     |Yes     |
|`H`     |8 bit |Yes     |Yes     |
|`L`     |8 bit |Yes     |Yes     |

`SetRegister` masks all seven registers to `$FF`.

The `PC` register is part of `T8008Registers`, but it is not exposed through
the current `GetRegister` or `SetRegister` case statements.

Names not handled by the `case` statement have no effect in `SetRegister` and
return `0` from `GetRegister`.

### Register enumeration

The public register enumeration contains seven registers:

|index|name|size     |
|-----|----|---------|
|0    |`A` |2 nibbles|
|1    |`B` |2 nibbles|
|2    |`C` |2 nibbles|
|3    |`D` |2 nibbles|
|4    |`E` |2 nibbles|
|5    |`H` |2 nibbles|
|6    |`L` |2 nibbles|

`GetRegisterCount` returns the number of entries in `PubRegNames`.
`GetRegisterName` returns the register name for a valid index and `nil`
otherwise. `GetRegisterSize` returns the corresponding register size in
nibbles and `0` for an invalid index.

The internal `RegNames` table also contains `M`, but `M` is not included in
the public register enumeration and there is no register pointer for it.

### T8008Registers

`T8008Registers` contains the seven 8-bit general-purpose registers and the
14-bit program counter:

|field|width                                          |
|-----|-----------------------------------------------|
|`A`  |8 bit                                          |
|`B`  |8 bit                                          |
|`C`  |8 bit                                          |
|`D`  |8 bit                                          |
|`E`  |8 bit                                          |
|`H`  |8 bit                                          |
|`L`  |8 bit                                          |
|`PC` |16-bit storage, limited to 14-bit address range|

### T8008Flags

`T8008Flags` contains the four Intel 8008 condition flags:

|field|description|
|-----|-----------|
|`C`  |Carry      |
|`Z`  |Zero       |
|`S`  |Sign       |
|`P`  |Parity     |

### T8008Stack

`T8008Stack` models the Intel 8008 internal seven-level hardware stack.

|field    |type                 |description                        |
|---------|---------------------|-----------------------------------|
|`Regs`   |`array[0..6] of Word`|Seven stored program-counter values|
|`Pointer`|`Byte`               |Current stack pointer/index        |

### State persistence

`LoadState` reads the following data in order:

|order|data                |
|-----|--------------------|
|1    |`FEnabled`          |
|2    |`FRegs`             |
|3    |`FFlags`            |
|4    |`FStack`            |
|5    |`FRunning`          |
|6    |`FHalted`           |
|7    |`FIRQPending`       |
|8    |`FNMIPending`       |
|9    |`FTotalCycles`      |
|10   |`FTotalInstructions`|

If a stream exception occurs, `LoadState` returns `False`; otherwise it returns
`True`.

`SaveState` writes the same fields in the same order and returns `True` after
the write operations complete.

### Exported plugin interface

The unit is compiled as the `cpu_8008` dynamic library and exports four plugin
entry points:

|exported name  |function    |description                                                                                    |
|---------------|------------|-----------------------------------------------------------------------------------------------|
|`cpu_create`   |`CreateCPU` |Creates and returns a new `T8008CPU` instance as `TCPU`.                                       |
|`cpu_destroy`  |`DestroyCPU`|Destroys the supplied CPU instance when it is assigned.                                        |
|`cpu_loadstate`|`LoadState` |Loads state through the supplied `TCPU` reference. Returns `False` when the reference is `nil`.|
|`cpu_savestate`|`SaveState` |Saves state through the supplied `TCPU` reference. Returns `False` when the reference is `nil`.|
