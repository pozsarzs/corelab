## T8080CPU from TCPU class in cpu_8080 unit

`T8080CPU` is the Intel 8080 processor implementation for the CoreLAB framework.
It derives from `TCPU` and implements the Intel 8080 register set, flag handling,
reset operation, state persistence, instruction stepping, interrupt reporting,
current-instruction reporting and register access.

The actual instruction implementation is included from `cpu_8080_microcode.pas`
during compilation. Therefore, the instruction set behaviour is distributed
between this unit and that included microcode source.

### CPU configuration

The constructor configures the inherited `TCPU` properties as follows:

|item                    |value                      |
|------------------------|---------------------------|
|Module name             |`8080`                     |
|Description             |`Intel 8080 microprocessor`|
|Architecture            |`arNeumann`                |
|Address width           |16                         |
|Endianness              |`enLittle`                 |
|Maximum memory address  |`$FFFF`                    |
|Maximum code address    |`$FFFF`                    |
|Maximum I/O port address|`$00FF`                    |
|Separate I/O bus        |`True`                     |
|Default clock frequency |2000000 Hz (2 MHz)         |

### Reset state

`Reset` disables execution, clears the halt and interrupt state, resets the
execution counters, clears the complete `T8080Registers` record and sets the
stack pointer to `$FFFF`.

|register/state     |value  |
|-------------------|-------|
|`PC`               |`$0000`|
|`SP`               |`$FFFF`|
|`Running`          |`False`|
|`Halted`           |`False`|
|`InterruptEnabled` |`False`|
|`FIRQPending`      |`False`|
|`FNMIPending`      |`False`|
|`TotalCycles`      |`0`    |
|`TotalInstructions`|`0`    |

The complete register record is cleared, so `A`, `B`, `C`, `D`, `E`, `H`, `L`
and `F` are all initially zero. The method emits the inherited `ceReset` event.

### Instruction execution

`Step` performs the following operations:

1. Stops immediately when the CPU is disabled (`FEnabled = False`).
2. Calls `CheckInterrupts`; execution stops immediately when an interrupt is accepted.
3. Stops immediately if the CPU is halted.
4. Reads the opcode from the system bus at the current `PC`.
5. Stores the address, opcode and operand count in `FLastInstruction`.
6. Increments `PC`.
7. Includes and executes the instruction implementation from
   `cpu_8080_microcode.pas`.
8. Adds the instruction cycle count to `FTotalCycles`.
9. Emits `ceInstructionBoundary`.
10. Increments `FTotalInstructions`.

The source therefore requires a connected `FBus` for opcode fetching.

### Flag handling

`UpdateFlags` updates the Intel 8080 flag register `F` according to the
arithmetic result.

|flag|meaning                                                      |
|----|-------------------------------------------------------------|
|`S` |Sign, bit 7 of the 8-bit result                              |
|`Z` |Zero, set when the 8-bit result is zero                      |
|`A` |Auxiliary Carry, calculated from bit 4 of the operands/result|
|`P` |Parity, set for even parity of the 8-bit result              |
|`C` |Carry, set when bit 8 of the 16-bit result is set            |

The Intel 8080 constant flag bits are also enforced: bits 5 and 3 are cleared
and bit 1 is set.

### Interrupt handling

`DoInterrupt` first calls the inherited interrupt handler. When `AEvent` is
`ceInterrupt`, further interrupts are disabled by clearing
`FInterruptEnabled`.

For an interrupt vector in the RST form (`FIRQVector >= $C0` and
`(FIRQVector and $07) = $07`), the current `PC` is pushed onto the stack as two
bytes and the `PC` is changed to the corresponding restart address:

`((FIRQVector shr 3) and $07) * 8`

For other interrupt instructions, the current source contains the handling
location but does not implement additional behaviour there.

`GetCurrentInterrupt` reports the current interrupt vector as two hexadecimal
digits. The `Flag` field is `EI` when interrupts are enabled and `DI` otherwise.
The `Status` field is `Pending` when `FIRQPending` is set; otherwise it is empty.
The `Sender` field is empty.

### Current-instruction information

`GetCurrentInstruction` returns a `TLogRec` containing:

1. the total instruction count;
2. the instruction address as four hexadecimal digits;
3. the opcode as a two-digit hexadecimal string, followed by encoded operands;
4. the mnemonic followed by formatted operand values;
5. the cycle count of the last instruction;
6. the accumulated total cycle count.

Up to two operands are included. Operand values are formatted as two-digit
hexadecimal values and two operands are separated by a comma in the mnemonic.

### Register access

`GetRegister` and `SetRegister` compare register names case-insensitively using
`UpperCase`.

|register|width |readable|writable|
|--------|------|--------|--------|
|`A`     |8 bit |Yes     |Yes     |
|`F`     |8 bit |Yes     |Yes     |
|`B`     |8 bit |Yes     |Yes     |
|`C`     |8 bit |Yes     |Yes     |
|`D`     |8 bit |Yes     |Yes     |
|`E`     |8 bit |Yes     |Yes     |
|`H`     |8 bit |Yes     |Yes     |
|`L`     |8 bit |Yes     |Yes     |
|`PC`    |16 bit|Yes     |Yes     |
|`SP`    |16 bit|Yes     |Yes     |

`SetRegister` masks the eight-bit registers to `$FF` and `PC` and `SP` to
`$FFFF`.

Names not handled by the `case` statement have no effect in `SetRegister` and
return `0` from `GetRegister`.

### Public register enumeration

The public register enumeration contains ten entries:

|index|name|size     |
|-----|----|---------|
|0    |`A` |2 nibbles|
|1    |`B` |2 nibbles|
|2    |`C` |2 nibbles|
|3    |`D` |2 nibbles|
|4    |`E` |2 nibbles|
|5    |`H` |2 nibbles|
|6    |`L` |2 nibbles|
|7    |`F` |2 nibbles|
|8    |`PC`|4 nibbles|
|9    |`SP`|4 nibbles|

`GetRegisterCount` returns the number of entries in `PubRegNames`.
`GetRegisterName` returns the register name for a valid index and `nil`
otherwise. `GetRegisterSize` returns the corresponding size in nibbles and `0`
for an invalid index.

### T8080Registers

`T8080Registers` provides both 16-bit register-pair access and individual 8-bit
register access through a variant record.

|16-bit register|8-bit representation|
|---------------|--------------------|
|`BC`           |`B`, `C`            |
|`DE`           |`D`, `E`            |
|`HL`           |`H`, `L`            |
|`AF`           |`A`, `F`            |
|`PC`           |`PCL`, `PCH`        |
|`SP`           |`SPL`, `SPH`        |

The register set therefore contains the Intel 8080 accumulator and flags,
general-purpose register pairs, program counter and stack pointer.

### Internal register names

The internal `RegNames` table uses the following order:

|index|name|
|-----|----|
|0    |`B` |
|1    |`C` |
|2    |`D` |
|3    |`E` |
|4    |`H` |
|5    |`L` |
|6    |`M` |
|7    |`A` |

`M` has no direct register pointer because it represents the memory location
addressed by `HL`.

### State persistence

`LoadState` reads the following data in order:

|order|data                |
|-----|--------------------|
|1    |`FEnabled`          |
|2    |`FRegs`             |
|3    |`FRunning`          |
|4    |`FHalted`           |
|5    |`FInterruptEnabled` |
|6    |`FIRQPending`       |
|7    |`FNMIPending`       |
|8    |`FTotalCycles`      |
|9    |`FTotalInstructions`|

If a stream exception occurs, `LoadState` returns `False`; otherwise it returns
`True`.

`SaveState` writes the same fields in the same order and returns `True` after
the write operations complete.

### Exported plugin interface

The unit is compiled as the `cpu_8080` dynamic library and exports four plugin
entry points:

|exported name  |function    |description                                                                                    |
|---------------|------------|-----------------------------------------------------------------------------------------------|
|`cpu_create`   |`CreateCPU` |Creates and returns a new `T8080CPU` instance as `TCPU`.                                       |
|`cpu_destroy`  |`DestroyCPU`|Destroys the supplied CPU instance when it is assigned.                                        |
|`cpu_loadstate`|`LoadState` |Loads state through the supplied `TCPU` reference. Returns `False` when the reference is `nil`.|
|`cpu_savestate`|`SaveState` |Saves state through the supplied `TCPU` reference. Returns `False` when the reference is `nil`.|
