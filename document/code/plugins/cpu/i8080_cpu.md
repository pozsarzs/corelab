# CoreLAB

## Source code

### Intel 8080 microprocessor implementation module (`i8080_cpu.md`)

**Class:** T8080CPU  
**Type:** non-visual component  
**File:** `plugins/i8080_cpu.pas`  
**Target:** Dynamic Linked Library or Shared Object  

|Type        |Name                                                               |Type/return value |Description                                                                                |
|:----------:|-------------------------------------------------------------------|:----------------:|-------------------------------------------------------------------------------------------|
| **Record** |`TLastInstruction`                                                 |`record`          |Record used to log the details of the last executed instruction.                           |
| **Record** |`T8080Registers`                                                   |`record`          |Variant record implementing the Intel 8080 register set.                                   |
| **Method** |`constructor Create;`                                              |`override;`       |Initializes CPU and architecture properties, sets up register pointers, and calls `Reset`. |
| **Method** |`procedure Reset;`                                                 |`override;`       |Resets registers to zero, sets `PC` to `0`, `SP` to `$FFFF`, and emits the `ceReset` event.|
| **Method** |`procedure Step;`                                                  |`override;`       |Executes a single instruction.                                                             |
| **Method** |`function GetCurrentInstruction: string;`                          |`override; string`|Returns the formatted textual representation of the last executed instruction.             |
| **Method** |`function GetRegister(const RegName: string): qword;`              |`override; qword` |Retrieves the current value of the specified register.                                     |
| **Method** |`procedure SetRegister(const RegName: string; Value: qword);`      |`override;`       |Sets the value of the specified register using appropriate bit masking.                    |
| **Method** |`procedure UpdateFlags(Value16: word; OldValue, ValueToAdd: byte);`|`protected;`      |Calculates and updates the `F` register status flags (`S`, `Z`, `AC`, `P`, `CY`)           |
|**Function**|`function CreateCPU: TCPU;`                                        |`stdcall/cdecl`   |Externally exported factory function that creates and returns a new `T8080CPU` instance.   |
