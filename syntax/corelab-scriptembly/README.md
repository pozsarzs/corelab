## Getting started

Clone directly the extension to your VSCode extension path as suggested:  

```
git clone git@github.com:pozsarzs/corelab-scriptembly.git ~/.vscode/extensions/
```

Related application:

```
git clone git@github.com:pozsarzs/corelab.git
```
