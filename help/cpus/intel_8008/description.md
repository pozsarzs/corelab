## Intel 8008 microprocessor

The Intel 8008, introduced in April 1972, was the world's first commercial 8-bit
microprocessor. It belongs to the LSI (Large Scale Integration) generation.
Originally commissioned by Computer Terminal Corporation (CTC) for use in
their Datapoint 2200 terminal, Intel released the chip independently after
CTC chose to implement their machine using standard TTL components instead.

### Technical Parameters

| Parameter                      | Specification                           |
| ------------------------------ | --------------------------------------- |
| **Release Date**               | April 1972                              |
| **Process Technology**         | 10 µm PMOS                              |
| **Transistor Count**           | 3,500 (LSI)                             |
| **Architecture**               | Neumann                                 |
| **Data Bus Width**             | 8-bit                                   |
| **Address Bus Width**          | 14-bit (multiplexed)                    |
| **Maximum Addressable Memory** | 16 KB (RAM/ROM)                         |
| **Clock Speed**                | 200 kHz to 800 kHz                      |
| **Instruction Set Size**       | 48 basic mnemonics (160 unique opcodes) |
| **Internal Stack**             | 7 levels deep (address stack)           |
| **General Purpose Registers**  | 7 (A, B, C, D, E, H, L)                 |
| **Package Type**               | 18-pin DIP                              |
