Intel 8008 microprocessor

Technical Parameters

Parameter Specification
Release date April 1972
Process technology 10 µm PMOS
Transistor count ~3,500
Architecture Neumann
Data bus width 8-bit
Address bus width 14-bit
Maximum addressable memory 16 kB
Maximum addressable I/O area 8 input ports + 8 output ports
Clock speed 500 kHz; 8008-1 up to 800 kHz
Stack 7-level × 14-bit call internal stack
General purpose registers A, B, C, D, E, H, L
Special registers PC, Flags
Interrupt handling One input; vector is supplied externally.

Flag abbreviations:

  • S - Sign Flag
  • Z - Zero Flag
  • P - Parity Flag
  • C - Carry Flag

Opcodes

Notes:

  • /: operation occurs/does not occur.
  • *: alternative opcodes; must not be used.
  • d8 or d16: 8-bit or 16-bit immediate data.
  • a16: 16-bit memory address.
