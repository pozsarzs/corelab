T8085CPU from T8080CPU class in cpu_8085 unit

T8085CPU is the Intel 8085 processor implementation for the CoreLAB framework. It derives from T8080CPU and extends the Intel 8080-compatible implementation with the Intel 8085 interrupt system, interrupt masking, interrupt checking, and 8085-specific opcode and cycle handling.

The 8085-specific instruction implementation is included from cpu_8085_microcode.pas during compilation. Opcodes not handled by that included source are passed to the inherited T8080CPU.RunOpCode method, after which selected instruction cycle counts are adjusted for the Intel 8085.

The constructor first calls the inherited constructor and then configures the CPU identity and clock frequency as follows. The other architecture properties are set to the same values as the inherited Intel 8080 implementation.

Reset state

Reset clears the execution and interrupt state, resets the execution counters, clears the inherited T8080Registers record, sets the stack pointer to $FFFF, and initializes the 8085 interrupt mask to $07.

register/state value

SP $FFFF

Halted False

FIRQMask $07
FIRQPending False
FNMIPending False

The complete inherited register record is cleared, so the 8080-compatible registers are initially zero. The method emits the inherited ceReset event.

Instruction execution

Step performs the following operations:

  1. Stops immediately when the CPU is disabled (FEnabled = False).
  2. Calls CheckInterrupts; execution stops immediately when an interrupt is accepted.
  3. Stops immediately if the CPU is halted.
  4. Reads the opcode from the system bus at the current PC.
  5. Stores the address, opcode and operand count in FLastInstruction.
  6. Increments PC.
  7. Calls RunOpCode to execute the opcode.
  8. Adds the instruction cycle count to FTotalCycles.
  9. Emits ceInstructionBoundary.
  10. Increments FTotalInstructions.

Opcode fetching therefore requires the inherited FBus to be connected.

Opcode and cycle handling

RunOpCode first checks the 8085-specific microcode included from cpu_8085_microcode.pas. If the opcode is not handled there, it calls the inherited T8080CPU.RunOpCode.

After inherited execution, the method adjusts the cycle count for the some instructions.

Interrupt handling

The unit defines the following interrupt mode constants:

constant value interrupt source
imINTR 0 INTR
imRST5_5 1 RST 5.5
imRST6_5 2 RST 6.5
imRST7_5 3 RST 7.5
imNMI 255 NMI (TRAP)

CheckInterrupts checks pending interrupts in the following order:

  1. NMI (FNMIPending), which is accepted independently of FInterruptEnabled.
  2. RST 7.5.
  3. RST 6.5.
  4. RST 5.5.
  5. INTR.

The mask register FIRQMask controls the three maskable RST inputs. Bit 0 masks RST 5.5, bit 1 masks RST 6.5, and bit 2 masks RST 7.5. A set bit causes the corresponding pending interrupt to be skipped. The maskable interrupts are checked only when FInterruptEnabled is True.

When an interrupt is accepted, its pending flag is cleared, the halted state is cleared, and DoInterrupt is called. Only one interrupt is accepted per check.

DoInterrupt first calls the inherited T8080CPU.DoInterrupt. For an accepted interrupt (AEvent = ceInterrupt), it disables further maskable interrupts by clearing FInterruptEnabled.

  • NMI (TRAP) pushes the current PC onto the stack and sets PC to $0024.
  • RST 5.5, RST 6.5 and RST 7.5 push the current PC onto the stack and set PC to $002C, $0034 and $003C, respectively.
  • INTR executes the opcode contained in FIRQVector[imINTR] by calling RunOpCode.

The return address is pushed as two bytes, with the high byte written first and the low byte written second as the stack pointer is decremented.

State persistence

LoadState reads the following data in order:

order data
1 FEnabled
2 FRegs
3 FRunning
4 FHalted
5 FInterruptEnabled
6 FIRQMask
7 FIRQPending
8 FNMIPending
9 FTotalCycles
10 FTotalInstructions

If a stream exception occurs, LoadState returns False; otherwise it returns True.

SaveState writes the same fields in the same order and returns True after the write operations complete.

Inherited functionality

The register set, register access methods, current-instruction reporting, current-interrupt reporting, flag handling and the base instruction implementation are inherited from T8080CPU. This unit overrides only the methods listed below and adds the FIRQMask field.
