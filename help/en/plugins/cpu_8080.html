T8080CPU from TCPU class in cpu_8080 unit

T8080CPU is the Intel 8080 processor implementation for the CoreLAB framework. It derives from TCPU and implements the Intel 8080 register set, reset operation, state persistence, instruction stepping, current-instruction reporting and register access.

The actual instruction implementation is included from microcode.pas during compilation. Therefore, the instruction set behaviour is distributed between this unit and that included microcode source.

Reset state

Reset clears the complete T8080Registers record and then explicitly assigns:

register/state value
PC $0000
SP $FFFF
Running False
Halted False

The method also emits the inherited ceReset event.

Instruction execution

Step performs the following operations:

  1. Calls CheckInterrupts; execution stops immediately when an interrupt is accepted.
  2. Stops immediately if the CPU is halted.
  3. Reads the opcode from the system bus at the current PC.
  4. Stores the address and opcode in LogRecord.
  5. Clears the operand count in the log record.
  6. Increments PC.
  7. Emits ceInstructionBoundary.
  8. Includes and executes the instruction implementation from microcode.pas.
  9. Increments the inherited instruction counter.

The source therefore requires a connected FBus for opcode fetching.

Current-instruction format

GetCurrentInstruction returns a tab-separated textual representation containing:

  1. the instruction address as four hexadecimal digits;
  2. the opcode as two hexadecimal digits;
  3. up to two encoded operand values;
  4. the mnemonic;
  5. the operand values again in the formatted operand portion.

The returned string is stored in the private s field before its character pointer is returned.

Register access

GetRegister and SetRegister compare register names case-insensitively using UpperCase.

register width readable writable
A 8 bit Yes Yes
F 8 bit Yes Yes
BC 16 bit Yes Yes
DE 16 bit Yes Yes
HL 16 bit Yes Yes
PC 16 bit Yes Yes
SP 16 bit Yes Yes

SetRegister masks A and F to $FF, and BC, DE, HL, PC and SP to $FFFF.

Names not handled by the case statement have no effect in SetRegister and return 0 from GetRegister.

State persistence

LoadState reads the following data in order:

order data
1 FEnabled
2 FRegs
3 FRunning
4 FHalted
5 FInterruptEnabled
6 FIRQPending
7 FNMIPending
8 FCycles
9 FInstructions

If a stream exception occurs, LoadState returns False; otherwise it returns True.

SaveState writes the same fields in the same order, but only when InstanceID > -1. When the instance ID is invalid, it returns False.

Mnemonic string[12] Instruction mnemonic.

T8080Registers

T8080Registers provides both 16-bit register-pair access and individual 8-bit register access through a variant record.

16-bit register 8-bit representation
BC B, C
DE D, E
HL H, L
AF A, F
PC PCL, PCH
SP SPL, SPH

The register set therefore contains the Intel 8080 accumulator, flags, general-purpose register pairs, program counter and stack pointer.

Register names

The internal register-pointer table uses the following order:

index name
0 B
1 C
2 D
3 E
4 H
5 L
6 M
7 A

M has no direct register pointer because it represents the memory location addressed by HL.
