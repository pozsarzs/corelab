TButton8 from TGIOPort class in ioport_button8 unit

This is an 8-button input, each button controls a specific bit within a Byte.

I/O behaviour

port description
0 Returns the pressed-button bit pattern and then releases all buttons; FDataOutNegation may invert the value. Other ports return FFh.
