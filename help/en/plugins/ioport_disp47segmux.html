TDisp47segMUX from TGIOPort class in ioport_disp47segmux unit

TIL302 style display; A0: direct inversable input, A1: select.

I/O behaviour

port description
0 Writes the selected TIL302-style digit in direct or BCD mode; bit 7 controls the right decimal point.
1 Selects the display digit, accepting indices from 0 to the last digit.
