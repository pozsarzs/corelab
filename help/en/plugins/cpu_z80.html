TZ80CPU from TCPU class in cpu_z80 unit

TZ80CPU is the Zilog Z80 processor implementation for the CoreLAB framework. It derives from TCPU and implements the Z80 register set, flag handling, reset operation, state persistence, instruction stepping, interrupt handling, interrupt reporting, current-instruction reporting and register access.

Reset state

Reset disables execution, clears the halt and interrupt-pending states, resets the execution counters, clears the complete TZ80Registers record and sets the stack pointer to $FFFF.

register/state value
PC $0000
SP $FFFF
Running False
Halted False
InterruptEnabled False
FIRQPending False
FNMIPending False
TotalCycles 0
TotalInstructions 0

Because the complete register record is cleared, the main and alternate register sets, the index registers, I, and R are initially zero. The method emits the inherited ceReset event.

The source does not explicitly reset FInterruptMode or FInterruptEnabled2. These fields are not part of TZ80Registers.

Instruction execution

Step performs the following operations:

  1. Stops immediately when the CPU is disabled (FEnabled = False).
  2. Calls CheckInterrupts; execution stops immediately when an interrupt is accepted.
  3. Stops immediately if the CPU is halted.
  4. Initializes the last-instruction address, cycle count, prefix count and operand count.
  5. Fetches bytes from the system bus at the current PC, incrementing PC after each fetch.
  6. Recognizes repeated DD and FD prefix bytes, records four cycles for each such prefix, and selects the corresponding prefix mode.
  7. Passes the final opcode and selected prefix to RunOpCode.
  8. Adds the instruction cycle count to FTotalCycles.
  9. Emits ceInstructionBoundary.
  10. Increments FTotalInstructions.

RunOpCode dispatches to one of seven included microcode sources according to the prefix mode: unprefixed, CB, DD, ED, FD, DDCB or FDCB. The supplied Step implementation explicitly consumes DD and FD prefixes; the handling of other prefix sequences depends on the included microcode.

The source requires a connected FBus for instruction fetching. Memory and I/O operations are delegated to the bus calls used by the microcode.

Flag handling

UpdateFlags updates the Z80 flag register F using the supplied result, original value, operand and two mode parameters.

flag meaning
S Sign, copied from bit 7 of the 8-bit result
Z Zero, set when the 8-bit result is zero
Y Undocumented flag bit 5, copied from bit 5 of the result
H Half-carry, calculated from bit 4 of the result and operands
X Undocumented flag bit 3, copied from bit 3 of the result
P/V Parity or arithmetic overflow, selected by the P parameter
N Add/subtract flag, set when the N parameter is True
C Carry, copied from bit 8 of the 16-bit result

When P is True, bit P/V is set for even parity. Otherwise, the method calculates arithmetic overflow, using subtraction rules when N is True and addition rules otherwise. The N parameter also controls the subtract flag.

Interrupt handling

CheckInterrupts checks the non-maskable interrupt first. If FNMIPending is set, it clears the pending flag, exits the halted state, calls DoInterrupt(ceInterrupt, imNMI), and reports that an interrupt was accepted.

It then checks the entries of FIRQPending in ascending index order. A maskable request is accepted only when its pending flag and FInterruptEnabled are both set. The selected pending flag is cleared, the halted state is exited, and DoInterrupt is called with the entry index as the mode argument. Only one interrupt is accepted per check.

DoInterrupt first calls the inherited interrupt handler. For a maskable interrupt it clears both FInterruptEnabled and FInterruptEnabled2, then pushes the current PC onto the stack, high byte first and low byte second.

  • NMI: sets PC to $0066, adds 11 cycles and returns.
  • IM 0: accepts the supplied vector only when it has the RST encoding (FIRQVector[AMode] >= $C0 and its low three bits are $07). The restart address is ((FIRQVector[AMode] shr 3) and $07) * 8; 13 cycles are added.
  • IM 1: sets PC to $0038 and adds 13 cycles.
  • IM 2: forms the vector-table address from I as the high byte and the supplied interrupt vector as the low byte. It reads the new PC as a little-endian word from that address and adds 19 cycles.

The interrupt mode is held in FInterruptMode. The source declares the constants imINT_IM0, imINT_IM1, imINT_IM2 and imNMI for the interrupt mode values 0, 1, 2 and 255 respectively.

NMI does nothing when the CPU is disabled. Otherwise it sets FNMIPending, copies FInterruptEnabled to FInterruptEnabled2, disables maskable interrupts and emits ceInterrupt.

GetCurrentInterrupt(AMode) reports the selected vector as two hexadecimal digits. The Flag field is EI when FInterruptEnabled is set and DI otherwise. The Status field is Pending when FIRQPending[AMode] is set; otherwise it is empty. The Sender field is empty.

Current-instruction information

GetCurrentInstruction returns a TLogRec containing:

  1. the total instruction count;
  2. the instruction address as four hexadecimal digits;
  3. the opcode as two hexadecimal digits, followed by up to two recorded operand bytes;
  4. the mnemonic, with one or two operands formatted when the mnemonic contains %, or appended as hexadecimal values otherwise;
  5. the last instruction’s cycle count;
  6. the total cycle count.

The method formats the opcode and recorded operands from FLastInstruction. The exact mnemonic and operand contents depend on the included microcode.

Eight-bit registers are masked with $FF; 16-bit registers are masked with $FFFF.

Unrecognized names do not change any register in SetRegister, and GetRegister returns 0.

TZ80Registers is a variant record providing access to both 16-bit register pairs and their individual 8-bit components.

The record also contains the 8-bit interrupt vector register I and refresh register R. The alternate register set is represented by the suffixed register pairs and bytes.

State persistence

LoadState reads the following data in order:

order data
1 FEnabled
2 FRegs
3 FLastInstruction
4 FRunning
5 FHalted
6 FInterruptEnabled
7 FInterruptEnabled2
8 FInterruptMode
9 FIRQPending
10 FNMIPending
11 FTotalCycles
12 FTotalInstructions

If a stream exception occurs, LoadState returns False; otherwise it returns True.

SaveState writes the same fields in the same order and returns True after the write operations complete.
