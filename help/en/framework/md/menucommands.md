# CoreLAB - Help

## 5. Menu Commands

The Menu Bar provides access to all the functions required to manage projects, configure modules, and control the simulation.

### 5.1 File

- **Switch to interactive mode:** Switches the application to interactive mode, allowing manual module management and simulation control.
- **Switch to script mode:** Switches the application to script mode for automated execution via `.clsce` scripts.
- **New project:** Creates a new, empty simulation project workspace.
- **Load project...:** Loads an existing CoreLAB project file (`.clprj`).
- **Save project:** Saves the current project configuration.
- **Save project as...:** Saves the current project configuration to a newly specified file.
- **Change work directory:** Sets the default working directory for file operations.
- **Settings...:** Opens the general settings dialog to configure UI colors and other layout preferences.
- **Restart application:** Restarts the CoreLAB application.
- **Exit:** Closes the application and returns to the operating system.

### 5.2 View

- **Show Module Explorer...:** Opens a tree-view window to manage all instantiated CPU, Memory, and I/O modules.
- **Show Breakpoint Manager...:** Opens a window to manage execution breakpoints.
- **Show BusLogger...:** Opens the BusLogger to monitor read and write operations on the system bus.
- **Show RunLogger...:** Opens the RunLogger to monitor real-time CPU instruction execution.
- **Show IntLogger...:** Opens the IntLogger to view hardware interrupt requests.
- **Show RegViewer...:** Opens the RegViewer to inspect the internal registers and flags of a specific processor.
- **Show HexViewer...:** Opens the HexViewer to inspect the data contents of a specific memory module.
- **Show ScriptEditor...:** Opens the integrated text editor for writing and modifying automation scripts.
- **Show ScriptConsole...:** Opens the console displaying text outputs generated by script commands.
- **Rename I/O panel...:** Allows renaming the interactive graphical panel of a selected I/O device.
- **Move/resize I/O panel...:** Allows modifying the position and dimensions of an I/O device's interactive panel.
- **Show I/O panel...:** Displays the interactive graphical panel for a selected I/O device.

### 5.3 Processor

- **Create...:** Instantiates and loads a new processor module from available plugins.
- **Destroy...:** Destroys and unloads the selected processor module.
- **Reset...:** Resets the selected processor to its initial hardware state.
- **Enable...:** Enables the selected processor module.
- **Disable...:** Disables the selected processor module.
- **Attach to bus...:** Connects the processor module to the simulated system bus.
- **Detach from bus...:** Disconnects the processor module from the system bus.
- **Properties...:** Opens the configuration window to edit the properties of the selected processor.

### 5.4 Memory

- **Create...:** Instantiates and loads a new memory module.
- **Destroy...:** Destroys and unloads the selected memory module.
- **Reset...:** Resets the selected memory module, clearing its temporary states.
- **Enable...:** Enables the selected memory module.
- **Disable...:** Disables the selected memory module.
- **Attach to bus...:** Connects the memory module to the simulated system bus.
- **Detach from bus...:** Disconnects the memory module from the system bus.
- **Properties...:** Opens the configuration window to edit the properties of the selected memory.
- **Load memory content...:** Loads binary (`.bin`) or Intel HEX (`.hex`) data into the memory module.
- **Save memory content...:** Saves the contents of the memory module to a `.bin` or `.hex` file.
- **Examine/deposit...:** Opens a tool to manually read or write individual bytes at specific memory addresses.

### 5.5 I/O port

- **Create...:** Instantiates and loads a new I/O port or device module.
- **Destroy...:** Destroys and unloads the selected I/O module.
- **Reset...:** Resets the selected I/O module to its initial state.
- **Enable...:** Enables the selected I/O module.
- **Disable...:** Disables the selected I/O module.
- **Attach to bus...:** Connects the I/O module to the simulated system bus.
- **Detach from bus...:** Disconnects the I/O module from the system bus.
- **Properties...:** Opens the configuration window to edit the properties of the selected I/O port or device.
- **Read/Write...:** Opens a tool to manually read from or write data to the specific I/O port.

### 5.6 Operation

- **Run:** Starts the continuous execution of the hardware simulation.
- **Step:** Executes a single processor instruction step in the simulation.
- **Stop:** Halts the running simulation.
- **NMI:** Triggers a Non-Maskable Interrupt on the attached processor.
- **Reset all attached module:** Sends a global reset signal to all CPUs, memory modules, and I/O ports connected to the system bus.
- **Make snapshot:** Saves the current execution state of the simulation.
- **Restore snapshot...:** Restores a previously saved simulation execution state.

### 5.7 Script

- **New script:** Creates a new, empty script.
- **Load script...:** Loads an existing script file (`.clsce`).
- **Save script:** Saves the current script.
- **Save script as...:** Saves the current script to a new file.
- **Run script:** Executes the loaded script automatically.
- **Step script:** Executes the script step-by-step, useful for debugging automation logic.
- **Stop script:** Halts the execution of the currently running script.

### 5.8 Help

- **Help:** Opens the CoreLAB Help viewer database.
- **About:** Displays information about the CoreLAB framework, its version, and copyright details.
