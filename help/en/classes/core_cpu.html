TCPU from core_cpu unit

TCPU is an abstract base class for processor implementations. It defines common CPU identity and architecture information, runtime state, execution statistics, interrupt handling, event notification and connection to an external ISysBus.

Processor-specific register access, reset, single-step execution, current-instruction reporting and state persistence are left abstract for derived CPU classes.
