TCPU from core_cpu unit

TCPU is an abstract base class for processor implementations. It defines common CPU identity and architecture information, bus configuration, runtime state, execution statistics, interrupt handling and event notification.

The class does not implement processor-specific register access, reset, single-step execution, current-instruction reporting or state persistence. These operations are left to derived CPU classes. Bus connection is also abstract and is implemented by the derived class.

Interrupt handling

The base class provides eight maskable interrupt channels, indexed from 0 to 7. IRQ(AVector, AMode) stores the vector and sets the pending flag for the selected channel. CheckInterrupts checks NMI first. If no NMI is pending, it scans the maskable channels in ascending index order and accepts the first pending IRQ when global maskable interrupts are enabled. Accepting an interrupt clears its pending flag and the CPU HALT state, calls DoInterrupt and returns True. At most one interrupt is accepted per call.

Both IRQ and NMI do nothing when the CPU is disabled. The base implementation of DoInterrupt only emits the supplied CPU event; its AMode parameter is not otherwise used there.
