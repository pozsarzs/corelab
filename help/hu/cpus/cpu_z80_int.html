Zilog Z80 mikroprocesszor

Megszakításkezelés

Ez a mikroprocesszor egy NMI (Nem maszkolható megszakítás) és egy INT bemenettel rendelkezik. Az NMI letilthatatlan, az INT, a EI és DI utasításokkal szoftveresen engedélyezhető vagy tiltható. Az INT-nek három üzemmódja van (IM0-2).

Működési elv

  • NMI: Nincs utasítás- vagy vektorátadás az adatbuszon. A CPU automatikusan a verembe menti a PC-t.
  • INT - IM0: A periféria egy gépi kódú utasítást (opkódot) tesz az adatbuszra.
  • INT - IM1: A perifériának nem kell adatot tennie a buszra. A CPU automatikusan generál egy belső RST 38H utasítást.
  • INT - IM2: A periféria nem opkódot, hanem egy 8-bites vektort (alsó címtöredéket) ad át az adatbuszon. Ez az érték a hardveres konvenciók miatt általában páros szám.

Átadható opkódok/vektor

  • NMI: nincs
  • INT - IM0: Bármilyen érvényes utasítás, de szinte kizárólag az egybájtos RST hívásokat használják.
  • INT - IM1: nincs
  • INT - IM2: vektor

Ugrási címek

  • NMI: Fix $0066.
  • INT - IM0: $0000, $0008, $0010, $0018, $0020, $0028, $0030, $0038.
  • INT - IM1: Fix $0038.
  • INT - IM2: A CPU egy 16-bites mutatót képez úgy, hogy a felső bájt a dedikált I (Interrupt) regiszterből jön, az alsó bájt pedig a buszról kapott vektor. A CPU kiolvassa az ezen a 16-bites címen (és a következőn) tárolt értéket, és erre a kiolvasott memóriacímre ugrik. Rendelkezésre áll egy teljes, 128 elemű megszakítási vektortábla bárhol a memóriában.
