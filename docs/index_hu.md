# CoreLAB
**Modular Processor Simulation Framework**

A CoreLAB egy funkcionális 8-bites mikroprocesszor és mikrokontroller szimulátor. Nem egy hagyományos zárt emulátor, hanem egy modern, szkriptelhető környezet a klasszikus architektúrák működésének és alacsony szintű programozásának tanulmányozására.

**Főbb jellemzők:**
* **Moduláris felépítés:** Építs egyedi virtuális hardverkörnyezetet dinamikusan betölthető CPU-kkal, memóriákkal és perifériákkal.
* **Saját modulok fejlesztése:** Írj egyedi processzor- vagy eszközmodult, akár egy teljesen saját virtuális CPU-t. Bármilyen programozási nyelvet használhatsz, amellyel `.so` vagy `.dll` fájlokat lehet készíteni.
* **Modern automatizáció:** Vezéreld a szimulációt parancssorból, írj teszteket és automatizálj a beépített szkriptnyelvvel.
* **Beépített diagnosztika:** Valós idejű regiszter- és memóriavizsgálat, lépésenkénti végrehajtás és busz-naplózás.
